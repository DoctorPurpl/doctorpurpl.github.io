ball and axe


Here you can see:

  • A dynamic speedrun split timer
  • A round end screen that displays your weekly and daily leaderboard position (lag is due to studio logging)
  • A leaderboard that displays your current position on either sort

-times may seem inaccurate due to testing settings
-leaderboards are handled completely on Roblox using datastores


ball and axe also contains:

  • A separate income source from breakable crates (that can also award you an item)
  • An inventory where you can buy items or random item crates
  • A character customization system
  • A highly customizable settings menu
  • A low gravity gamepass unlocked mode
  • Not in videos: Localized interactable objects such as buttons or levers that can spawn boxes or activate fans that blow the player around; Super effective physics based anti-cheat
    -all of this is fully playable
    -spectate and color picker features were not made by me
    ball and axe is in total only 8300 lines

War Engines


This video presents:

  • Instantaneous vehicle block assembly using largely constraints
  • Motor torque is calculated correctly to each wheel and accepts all input types
  • Loss of traction causes smoke depending on the surface (such as from hard braking)
  • Cannons have recoil that can be used as a thrust
  • Cannons only shoot if within an angle of the target
  • Blocks and structures either take damage until they break or break from an impact too strong
  • Modular source of income from the end of a run


Shown here:

  • Intuitive building controls, with dedicated controls for mobile and for console
  • Block shop that shows contents and their percentage chances (each crate can award multiple blocks)
  • Not in videos: Modular and incredibly simple to use weather system
    -all of this is fully playable
    War Engines is in total only 4600 lines

Tower Defense Unfinished Project


This video displays:

  • A round system with a ready up to skip intermission mechanic
  • An enemy system that only renders the characters locally
  • A turret placement system
  • And a player chosen weapon that is able to damage enemies in multiple different ways such as with the lightning ability which dynamically chains damage

The same project also included:

  • A shop for turrets and staffs
  • A fully functional match making system that initializes all round systems

Cardboard Aliens


This game had prominently:

  • A building system which affected a very simple resource effective node based custom path finding system
  • A basic gun system
  • Grenades
  • Immersive shops
  • A round and level system
  • 16 easily customizable wave and a boss enemy with custom attacks
  • A Risk of Rain inspired item system that granted stat boosts
    -Datastore2 module used for this game not made by me

Custom car chassis

  • Completely force driven wheels/tires with a constraint based chassis
  • This chassis presents also Ackermann steering, torsion bars and double wishbone suspension (although with inverted geometry)
  • Other chassis can be seen in the background; they are all physics driven but have tons of differing characteristics like a solid rear axle, simpler chassis, and so on

Projectile based weapon system


Here you can see:

  • A dynamic crosshair that responds both to shots and player movement
  • Running
  • Basic recoil
  • Weapon swapping system


This project also has:

  • Some debug tools made for it (graphing tool and variable tracker)
  • A basic implementation of Roblox's path finding service

Sticky hands commission

  • Fully replicated throwable sticky hands that stick only to desired objects
  • Hands were made to be a completely independent, easily multipliable system
  • This was written completely in OOP
